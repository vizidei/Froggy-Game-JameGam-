# Froggy

A top-down arcade game made in 2 days for the JAME GAM GAME JAM by hackclub.
Theme: **"Just a Little Guy"**.

You play a tiny frog with a hugely oversized weapon, defending a set of
floating lilypads from swarms of bugs. Smash them, launch them away,
and survive as long as you can.

https://iediziv.itch.io/froggy

## Controls

| Action | Input |
|---|---|
| Move | WASD / Arrow keys |
| Dash (toward the cursor) | Space |
| Swing weapon (aims at the cursor) | Left click |

## Features

- Dash across gaps between lilypads. The water slows you down and hurts you.
- Weapon swing with screen shake that launches bugs as ragdolls.
- Combo-based scoring with floating point popups.
- Flowers spawn on the lilypads over time and heal the frog.
- Three enemy types: mosquitos, charging dragonflies and splitters.
- Each swing jolts the mouse cursor, which affects your next dash.

## Built with Godot V 4.7

## Project structure

- `scenes/` — player, weapon, enemies, lilypads, flowers, UI
- `scripts/` — GDScript files
- `assets/` — sprites and sounds
